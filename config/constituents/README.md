These CSVs follow the niftyindices.com constituent-list format
(Company Name, Industry, Symbol, Series, ISIN Code). Only Symbol and Series are read.

The seed lists are hand-written and need checking: index membership changes at every
semi-annual rebalance. Refresh them with the official files using `jobs constituents`
(verify the niftyindices host first), or download them by hand from the index pages.
